## 1. 环境准备

### 1.1 安装依赖

```bash
pip install -r requirements.txt
```

主要依赖：`ai2thor`、`ultralytics`、`openai-clip`、`opencv-python`、`numpy`、`pyyaml`、`python-dotenv`、`openai`、`pillow`

### 1.2 配置 API 密钥

复制模板并填写密钥：

```bash
cp .env.example .env
```

编辑 `.env` 文件：

```
OPENAI_API_KEY=your_api_key_here
OPENAI_BASE_URL=https://api.openai.com/v1
VLM_MODEL=gpt-4o
```

- `OPENAI_API_KEY`：OpenAI 或兼容 API 的密钥
- `OPENAI_BASE_URL`：API 端点地址（可使用代理或兼容服务）
- `VLM_MODEL`：VLM 模型名称（如 `gpt-4o`、`deepseek-chat` 等）

### 1.3 模型权重

确保存在以下模型文件：

| 文件 | 用途 |
|---|---|
| `weights/yolov8n.pt` | YOLOv8-nano 基础模型（感知 Demo 默认） |
| `weights/yolov8m.pt` | YOLOv8-medium 基础模型（精度更高，速度较慢） |
| `runs/detect/runs/train/weights/best.pt` | 微调后的模型（决策 Demo 默认） |
| `runs/detect/runs/train/weights/last.pt` | 微调最后一个 epoch 的检查点 |

**YOLO-World 开放词汇模型**（可选，首次运行自动下载，~200 MB）：

| 模型 | 说明 |
|---|---|
| `yolov8s-worldv2.pt` | 推荐：速度和精度的最佳平衡 |
| `yolov8m-worldv2.pt` | 精度更高 |
| `yolov8l-worldv2.pt` | 最高精度（需要 GPU） |

YOLO-World 模型首次使用时会从 Ultralytics 服务器自动下载。

首次使用感知或采集功能时，AI2-THOR 会自动下载 Unity 环境（约 1-2 GB），请保持网络通畅。

最基础的交互入口，用于熟悉场景、自由探索、调试感知。

```bash

```

| 参数 | 默认值 | 说明 |
|---|---|---|
| `--scene` | `FloorPlan1` | 场景名称，范围 FloorPlan1 ~ FloorPlan30 |

| `--height` | `600` | 窗口高度（像素） |

### 2.2 交互命令

#### 移动控制

| 按键 | 功能 |
|---|---|
| `w` | 前进 0.25m |
| `s` | 后退 0.25m |
| `a` | 左转 90° |
| `d` | 右转 90° |
| `q` | 微调左转 30° |

## 3. 感知模块 Demo (`perceive.py`)

专注于视觉感知功能的调试与验证。

### 3.1 启动

```bash
python src/cli/perceive.py \
    [--scene FloorPlan1] \
    [--width 800] [--height 600] \
    [--model yolov8n.pt] \
    [--confidence 0.3] \
    [--clip] \
    [--clip-threshold 0.0] \
    [--clip-detect "door,window"] \
    [--clip-detect-threshold 0.28] \
    [--clip-detect-iou 0.5] \
    [--no-prior] \
    [--classes config/classes.yaml]
```

### 3.2 参数说明

| 参数 | 默认值 | 说明 |
|---|---|---|
| `--scene` | `FloorPlan1` | 场景名称 |
| `--width` | `800` | 窗口宽度 |
| `--height` | `600` | 窗口高度 |
| `--model` | `yolov8n.pt` | YOLO 模型路径（支持 n/s/m/l/x 变体或微调后的 best.pt） |
| `--confidence` | `0.3` | YOLO 检测置信度阈值（低于此值的检测被过滤） |
| `--clip` | 关闭 | 启用 CLIP 验证器（对 YOLO 检测框进行二次验证） |
| `--clip-threshold` | `0.0` | CLIP 验证相似度阈值 |
| `--clip-detect` | 无 | CLIP 零样本检测目标，逗号分隔（如 `door,window,cabinet`） |
| `--clip-detect-threshold` | `0.28` | CLIP 零样本检测置信度阈值 |
| `--clip-detect-iou` | `0.5` | CLIP 零样本检测 NMS IoU 阈值 |
| `--no-prior` | 关闭 | 禁用场景先验（房间类型加权） |
| `--classes` | `config/classes.yaml` | 类别配置文件路径 |

### 3.3 诊断参数

| 参数 | 功能 |
|---|---|
| `--check-classes` | 列出所有类别及 AI2-THOR 映射状态（不启动交互） |
| `--verify-labels` | 可视化 YOLO 标注框于场景图像上（用于验证数据质量） |

### 3.4 交互命令

| 命令 | 功能 |
|---|---|
| `w/a/s/d/q/e` | 移动控制（同手动 Demo） |
| `detect` | 运行完整感知管道：YOLO → CLIP 零样本检测 → 场景先验 → CLIP 验证 → 深度估计 |
| `clip` | 切换 CLIP 验证器的开关 |
| `prior` | 切换场景先验的开关 |
| `auto` | 切换自动检测模式（每次移动后自动运行感知） |
| `info` | 显示 Agent 状态 |
| `quit` | 退出 |

### 3.5 YOLO-World 开放词汇检测

YOLO-World 可以在不微调的情况下检测任意类别，只需提供类别名称列表。

```bash
# 使用 YOLO-World 替代标准 YOLO
python src/cli/perceive.py \
    --yolo-world \
    --model yolov8s-worldv2.pt \
    --confidence 0.15 \
    --scene FloorPlan1

# 指定自定义类别文件
python src/cli/perceive.py \
    --yolo-world \
    --model yolov8s-worldv2.pt \
    --classes config/classes.yaml
```

**YOLO-World 与标准 YOLO 的差异**：
- 置信度阈值建议更低（0.10–0.20），因为开放词汇检测分数整体偏低
- 无需微调即可检测新类别——在 `classes.yaml` 添加名称后直接生效
- 模型首次使用时会自动下载（约 200 MB）

### 3.6 感知管道流程

```
当前帧 → YOLO 检测 → CLIP 零样本检测 → 场景先验加权 → CLIP 验证过滤 → 深度估计 → AI2-THOR 真实距离覆盖
```

- **深度分级**：NEAR（≤1.5m）/ MEDIUM（1.5~3.0m）/ FAR（≥3.0m）
- **屏幕位置**：left / center / right

## 4. 决策模块 Demo (`decide.py`)

端到端的任务执行 Demo，支持三种检测模式、两种决策策略。

### 4.1 启动

#### 默认模式（Hybrid 检测器，推荐）

```bash
python src/cli/decide.py \
    --scene FloorPlan1 \
    --policy rule \
    --detector hybrid \
    --model runs/detect/runs/train/weights/best.pt
```

Hybrid 模式自动结合微调 YOLO 和 YOLO-World，无需额外配置。

#### 微调 YOLO 模式

```bash
python src/cli/decide.py \
    --detector finetuned \
    --model runs/detect/runs/train/weights/best.pt
```

#### YOLO-World 模式

```bash
python src/cli/decide.py \
    --detector yolo-world \
    --model yolov8s-worldv2.pt \
    --confidence 0.15
```

#### 单次任务模式

```bash
# Rule 策略（无 API，快速）
python src/cli/decide.py \
    --scene FloorPlan1 \
    --task "Go to the refrigerator and open it" \
    --policy rule \
    --max-steps 200

# LLM 策略（VLM 每步多模态，需要 OPENAI_API_KEY）
python src/cli/decide.py \
    --scene FloorPlan1 \
    --task "Go to the refrigerator and open it" \
    --policy llm \
    --vlm-model qwen-vl-max \
    --max-steps 200
```

### 4.2 参数说明

| 参数 | 默认值 | 说明 |
|---|---|---|
| `--scene` | `FloorPlan1` | 场景名称 |
| `--task` | 无 | 自然语言任务指令（指定后立即执行，否则进入交互模式） |
| `--policy` | `rule` | 策略类型：`rule`（确定性规则）或 `llm`（VLM 驱动） |
| `--max-steps` | `200` | 最大执行步数（防止死循环） |
| `--model` | `runs/detect/runs/train/weights/best.pt` | YOLO 模型路径 |
| `--confidence` | `0.3` | YOLO 检测置信度阈值 |
| `--vlm-model` | `.env` 中的值 | LLM 策略使用的 VLM 模型 |
| `--clip` | 关闭 | 启用 CLIP 验证 |
| `--no-prior` | 关闭 | 禁用场景先验 |
| `--no-record` | 关闭 | 禁用帧录制 |
| `--no-export` | 关闭 | 禁用自动视频导出 |
| `--no-frames` | 关闭 | 禁用带标注帧的保存 |
| `--detector` | `hybrid` | 检测模式：`hybrid`（微调+YOLO-World）、`finetuned`（仅微调）、`yolo-world`（仅YOLO-World） |

### 4.3 交互命令

| 命令 | 功能 | 示例 |
|---|---|---|
| `run <指令>` | 执行自然语言任务 | `run Go to the kitchen and find the microwave` |
| `rule` | 切换到 RulePolicy（无 API） | — |
| `llm` | 切换到 LLMPolicy（VLM 每步多模态） | — |
| `hybrid` / `rule+vlm` | 切换到 Rule + VLM 紧急恢复 | — |
| `info` | 显示 Agent 当前状态 | — |
| `detect` | 在当前视图运行感知 | — |
| `list` | 列出场景物体 | — |
| `quit` | 退出 | — |

### 4.4 支持的任务指令示例

#### 导航类

```text
Go to the chair
Find the bed
Walk to the kitchen counter
```

#### 交互类

```text
Open the refrigerator
Pick up the mug
Turn on the lamp
Toggle the light switch
```

#### 复合任务

```text
Go to the bathroom and open the cabinet
Find the apple and pick it up
```

### 4.5 三种策略对比

| 特性 | RulePolicy | LLMPolicy (Phase 4) | Rule+VLM (Phase 3) |
|---|---|---|---|
| 需要 API | 否 | 是（VLM，每步） | 是（VLM，仅丢失时） |
| 速度 | 快（毫秒级） | 慢（API 延迟 × 每步） | 中（偶尔 API 调用） |
| 发送图像 | 否 | **每帧都发** | 仅 Before/After |
| 泛化能力 | 有限（依赖关键词匹配） | 强（视觉+语言理解） | 中 |
| 别名处理 | 内置 15 个别名 | 视觉识别，自动理解 | 同 Rule |
| 适用场景 | 简单导航、快速测试 | 复杂任务、需要视觉理解 | 折中，省 API 费用 |

### 4.6 RulePolicy 算法

1. **解析指令** → 提取目标物体和交互动作
2. **模糊匹配** → 精确匹配 → 别名匹配（如 `fridge`→`refrigerator`、`sofa`→`couch`）→ 子串匹配
3. **感知引导接近**：若目标可见
   - 距离 ≤1.0m 且居中 → STOP
   - 否则根据位置（left/center/right）转动 + 前进
4. **不可见时**：最多旋转扫描 4 次，仍不可见则回退到 A* 导航（`NAVIGATE_TO:<target>`）

## 5. 感知微调流程

当需要检测新类别或提升检测精度时，遵循以下流程：

### 5.1 步骤一：配置类别

编辑 `config/classes.yaml`：

```yaml
names:
  - person        # 0
  - chair         # 1
  # ... 80 个 COCO 类别
  - cabinet       # 80
  - curtain       # 81
  # ... 34 个 AI2-THOR 扩展类别

thor_to_names:
  Cabinet: cabinet
  Curtains: curtain
  # ... 新类别映射
```

**关键原则**：新增类别只需修改此 YAML 文件，无需改动 Python 代码。

### 5.2 步骤二：采集数据

```bash
python -m src.perception.finetune.collect
```

此命令会：
- 在 FloorPlan1-10 中随机行走
- 利用 AI2-THOR 实例分割自动标注
- 在 `data/images/train/` 保存图像
- 在 `data/labels/train/` 保存 YOLO 格式标签
- 自动生成 `data/data.yaml`

### 5.3 步骤三：微调训练

```bash
python -m src.perception.finetune.train \
    --data data/data.yaml \
    --base-model weights/yolov8n.pt \
    --epochs 50 \
    --imgsz 640 \
    --device cpu \
    --batch 16 \
    --lr0 0.01 \
    --project runs/detect \
    --name train
```

| 参数 | 默认值 | 说明 |
|---|---|---|
| `--data` | `data/data.yaml` | 数据集配置文件 |
| `--base-model` | `weights/yolov8n.pt` | 基础模型 |
| `--epochs` | `50` | 训练轮数 |
| `--imgsz` | `640` | 输入图像尺寸 |
| `--device` | `cpu` | 训练设备（`cpu` 或 `cuda:0`） |
| `--batch` | `16` | 批次大小 |
| `--lr0` | `0.01` | 初始学习率 |
| `--project` | `runs/detect` | 输出项目目录 |
| `--name` | `train` | 运行名称 |
| `--resume` | 关闭 | 从上次中断处恢复训练 |

### 5.4 步骤四：评估

```bash
python -m src.perception.finetune.eval
```

评估指标：
- **mAP@0.5**：IoU 阈值 0.5 时的平均精度
- **mAP@0.5:0.95**：IoU 阈值 0.5~0.95 的平均精度
- **Precision**：精确率
- **Recall**：召回率

验证集来自 FloorPlan11-15（与训练集不重叠）。

### 5.5 微调结果参考

| 指标 | 微调前 | 微调后 |
|---|---|---|
| mAP@0.5 | 0.027 | 0.672 |

## 6. 录制与导出

所有 Demo 均内置 `FrameCollector`，录制功能默认开启。**退出时自动导出两项内容：MP4 轨迹视频 + PNG 标注帧序列。**

### 6.1 输出目录结构

```
outputs/20260526_143025_FloorPlan1/
├── frames/                  # 标注帧序列（带位置叠加的 PNG）
│   ├── frame_0000.png
│   ├── frame_0001.png
│   └── ...
├── screenshots/             # 手动截图（shot 命令）
├── trajectory.mp4           # 轨迹视频
└── step_0001.png ...        # 检测标注帧（perceive.py / decide.py）
```

> **两种标注帧的区别**：
> - `frames/frame_*.png`：由 `export_frames()` 生成，叠加了位置/动作/步数信息
> - `step_*.png`：由检测时实时保存，叠加了 YOLO 检测框和距离标签

### 6.2 导出方式

| 方式 | 触发条件 | 说明 |
|---|---|---|
| **自动导出** | 退出时默认触发 | 同时导出 MP4 视频 + 全部帧 PNG 序列 |
| 手动视频 | 输入 `video` 命令 | 仅限 manual.py |
| 手动帧 | 输入 `frames` 命令 | 仅限 manual.py |
| 单帧截图 | 输入 `shot` 命令 | 仅限 manual.py |

### 6.3 禁用录制

在 `decide.py` 中可通过以下参数控制：

```bash
# 完全禁用录制
python src/cli/decide.py --no-record ...

# 禁用视频自动导出（仍保存标注帧）
python src/cli/decide.py --no-export ...

# 禁用检测标注帧保存
python src/cli/decide.py --no-frames ...
```

## 8. 常见工作流

### 8.1 探索场景

```bash
# 启动手动控制，自由探索
python src/cli/manual.py --scene FloorPlan1

# 交互式命令
list          # 查看所有物体
where Chair   # 查看椅子距离
go Table      # 自动导航到桌子
desc          # VLM 描述当前场景
```

### 8.2 调试感知效果

```bash
# 方式一：微调 YOLO 模型
python src/cli/perceive.py --scene FloorPlan5 --clip --model runs/detect/runs/train/weights/best.pt

# 方式二：YOLO-World 开放词汇（无需微调，推荐快速验证）
python src/cli/perceive.py --yolo-world --model yolov8s-worldv2.pt --confidence 0.15 --scene FloorPlan5

# 交互式命令
detect        # 运行感知管道，观察检测结果
clip          # 切换 CLIP 验证开/关，对比效果
prior         # 切换场景先验开/关，对比效果
auto          # 开启自动检测，边移动边看结果
```

### 8.2.1 对比评估两种检测器

```bash
# 随机选 3 个场景，各走 100 步，对比 YOLO-World vs 微调 YOLO
python -m src.perception.eval_detectors --scenes 3 --steps 100

# 指定场景范围
python -m src.perception.eval_detectors --scenes 2 --start-scene 5 --steps 150

# 自定义置信度
python -m src.perception.eval_detectors --yolo-conf 0.3 --world-conf 0.15
```

输出目录 `outputs/eval_<时间戳>/` 包含：
- `per_frame.csv` — 每一帧的 TP/FP/FN/Precision/Recall/F1
- `summary.txt` — 整体对比表

终端输出示例：
```
  OVERALL RESULTS  (87 frames, 3 scenes)
