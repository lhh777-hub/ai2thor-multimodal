# LLM 策略导航问题修复记录

**日期**: 2026-05-19
**策略**: LLM 混合策略 (LLM Hybrid)

---

## 修复 1: Agent 震荡循环

### 问题描述

使用 LLM 策略进行导航 `go to the door` 时，agent 在目标不可见阶段陷入反复震荡：

- Step 8: loop detection 触发 `MOVE_FORWARD`（`Breaking oscillation loop`）
- Step 9+: LLM 再次输出 `TURN_LEFT` → `TURN_RIGHT` → …，反复循环
- 100 个 step 用完后仍无法找到目标，agent 在原地打转

### 根因

Loop detection 只打断了单次震荡，但没有阻止 LLM 下一步又回到同样的 turning 模式。缺少"打破循环后持续向前探索"的机制。

### 解决方案

**修改文件**: `src/decision/llm_policy.py`

4 项改进：

1. **Post-Loop Momentum 机制（核心）**: loop detection 触发后设置 `_post_loop_momentum = 2`，强制 agent 连续向前 3 步 (0.75m)，离开震荡区域后再交还给 LLM

2. **System Prompt 重写**: 6 条编号规则，明确禁止 LEFT/RIGHT 交替，要求 2 次 turn 后必须 forward

3. **Loop Detection 增强**: 新增 small-turn 震荡模式检测，降低检测阈值（`forward_count <= 1` 即触发）

4. **Observation Message 优化**: 用 `->` 箭头展示最近动作序列，精简字段名

### 决策优先级（修复后）

```
Priority 1: Collision            → 确定性地转向避障
Priority 2: Target visible       → 确定性地接近目标
Priority 3: Post-loop momentum   → 强制向前（新机制）
Priority 4: Loop detected        → 强制向前 + 设置 momentum
Priority 5: LLM exploration      → 调用 LLM 做探索决策
```

## 修复 2: Agent 无法识别目标导致不停止

### 问题描述

修复 1 后 agent 探索行为改善，能逐步向 door 靠近，但到达目标后不停止，继续向前走。

### 根因分析

`go to the door` 这个指令的完整决策链路：

```
User: "go to the door"
  → TaskParser: target_object = "door"
  → YOLO: 检测画面中所有物体 (COCO 80类，不含 door)
  → _filter_target_candidates: 用 "door" 匹配 YOLO label → 空列表
  → CLIPMatcher: detections 为空 → 返回 None
  → target_found = False
  → Priority 2 (目标接近+STOP) 永远不触发
  → Agent 永远不 STOP
```

**根本原因**: COCO 数据集的 80 个类别中不包含 `door`，YOLO 无法检测门。后续 CLIP 匹配和距离估计链路全部断裂。

### 解决方案

**修改文件 1**: `src/perception/pipeline.py`

CLIP fallback 机制：当 YOLO 的名称过滤返回空列表时，将所有 raw_detections 传给 CLIP 进行视觉匹配。CLIP 可以在任意检测到的物体中寻找与 "door" 视觉最相似的。

```python
dets_for_match = target_candidates if target_candidates else raw_detections
target = self.matcher.match(task.instruction, observation.rgb_image, dets_for_match)

# 使用 CLIP 分数阈值 0.22 过滤假阳性
if target is not None and not target_candidates and target.clip_score < 0.22:
    target = None
```

**修改文件 2**: `src/agent/runner.py`

距离安全网：在每个 step 执行前，通过 AI2-THOR 的 `distance_to_object()` 检查 agent 与目标的真实距离。若距离 < success_distance，强制 STOP，不依赖感知管道的结果。

```python
real_dist = self.controller.distance_to_object(task.target_object)
if real_dist is not None and real_dist < success_dist:
    decision.action = "STOP"
    break
```

这意味着：即使 YOLO+CLIP 完全检测不到目标，只要 agent 在探索中偶然靠近目标物体，就会自动终止并标记成功。

### 效果对比

| 场景 | 修复前 | 修复后 |
|------|--------|--------|
| YOLO 能检测的目标 (chair, sofa) | 可能震荡 | 正常接近+停止 |
| YOLO 不能检测的目标 (door) | 迷茫探索，永不停止 | CLIP 视觉匹配 + 距离安全网 |
| 100 步后状态 | 仍在无效循环 | 到达目标或真正未找到 |
