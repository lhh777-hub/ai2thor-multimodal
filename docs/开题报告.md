## 一、选题背景与研究目标

### 1.1 选题背景

具身智能（Embodied AI）是让智能体在三维环境中通过感知、理解和行动完成任务的 AI 前沿方向。随着多模态大模型（如 CLIP、GPT-4V）的发展，智能体已具备将自然语言指令转化为环境行动的潜力。

本项目选择 **AI2-THOR** 作为仿真平台。相比 Habitat-Sim 和 iGibson，AI2-THOR 部署简单、室内场景丰富（120+ iTHOR 场景）、支持物体交互（开/关/拾取）、并提供内置 episode 可视化，适合课程项目快速验证。

### 1.2 研究目标

构建一个接收自然语言指令、在 AI2-THOR 室内场景中自主导航和交互的多模态智能体：

- **基础任务（ObjectNav）：** 输入 "Go to the red chair"，智能体自动搜索并靠近目标
- **扩展任务（交互）：** 输入 "Open the fridge"，导航到目标后执行交互动作
- **核心对比：** 纯视觉规则策略 vs 视觉+语言 LLM 策略的性能差异

## 二、技术路线

### 2.1 系统架构

```
自然语言指令 → 任务解析(LLM) → AI2-THOR(RGB帧) → YOLO检测 → CLIP语义匹配 → 深度估计 → 决策(规则/LLM) → 动作执行 → 循环
```

系统采用"感知—决策—执行—评估"四层模块化架构，6 个核心模块通过统一数据结构通信。

### 2.2 技术选型


| 模块     | 技术                      | 说明                             |
| -------- | ------------------------- | -------------------------------- |
| 仿真环境 | AI2-THOR iTHOR            | 室内场景、离散动作、物体交互     |
| 目标检测 | YOLOv8                    | 候选物体检测 + 边界框            |
| 语义匹配 | CLIP                      | 文本-图像相似度，开放词表匹配    |
| 距离估计 | Depth Anything V2         | 单目深度，分级为 NEAR/MEDIUM/FAR |
| 决策     | 小型LLM（7B） / 规则策略 | 双策略可切换，支持降级回退       |
| 评估     | SPL, Success Rate         | 含轨迹可视化与失败分析           |

### 2.3 两种决策策略

- **规则 Baseline：** 纯视觉驱动——不可见→旋转搜索，左侧→左转，右侧→右转，中央远→前进，中央近→停止
- **LLM 策略：** 综合自然语言指令、CLIP 匹配分数、距离等级、动作历史，由 llm 生成动作，含合法性校验和规则回退

两者通过统一的 `DecisionPolicy` 接口实现，配置文件切换，便于对比实验。

## 三、开发计划


| 阶段            | 内容                                                          | 交付物                  |
| --------------- | ------------------------------------------------------------- | ----------------------- |
| **1. 环境基础** | WSL2 + AI2-THOR 安装、控制器封装、数据结构定义、手动控制 demo | 场景加载 + RGB 采集     |
| **2. 感知闭环** | YOLO 检测、启发式距离估计、规则策略、episode 主循环           | 自动导航 + Success Rate |
| **3. LLM 决策** | CLIP 匹配、LLM 决策、Depth Anything V2、批量实验 + 评估      | 规则 vs LLM 对比 + SPL  |
| **4. 收尾完善** | 轨迹可视化、可选交互扩展、失败案例分析、技术报告              | 完整交付物              |

每阶段结束均有可运行成果，渐进式推进，降低风险。

## 四、评估方案

### 评估指标

- **Success Rate：** 成功 episode 占比
- **SPL：** 综合衡量导航成功率与路径效率
- **平均路径长度 / 平均步数 / 平均决策耗时**

### 实验设计


| 实验组          | 输入                                    | 决策方式 |
| --------------- | --------------------------------------- | -------- |
| 纯视觉 Baseline | RGB + 检测框 + 目标类别                 | 规则策略 |
| 视觉+语言 Agent | RGB + 自然语言 + YOLO + CLIP + 距离等级 | LLM 策略 |

每类任务 ≥10 个 episode，覆盖多场景多目标。

---

## 五、预期成果与风险应对

### 预期成果

1. 完整模块化源代码 + 命令行交互 Demo
2. 10+ episode 可视化轨迹视频
3. 规则 vs LLM 性能对比表（SPL、Success Rate 等）
4. ≥3 个失败案例分析
5. 系统演示视频 + 技术报告

### 风险应对


| 风险                    | 应对方案                   |
| ----------------------- | -------------------------- |
| YOLO 对仿真物体检测不足 | CLIP 重排序 / 限定常见类别 |
| 深度模型推理慢          | 启发式距离替代             |
| LLM 输出不稳定          | 白名单过滤 + 规则回退      |
| 导航局部循环            | 循环检测 + 最大旋转限制    |
